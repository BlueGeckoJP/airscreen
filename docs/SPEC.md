# AirScreen 仕様

## 概要

画面データを低遅延で別PCに一方向配信するプログラム。データが壊れていても破綻しない設計。

## システム構成

### 役割分担

- **送信側**: 画面キャプチャ + データ送信
- **受信側**: データ受信 + 画面描画

### 通信仕様

- **データフロー**: 送信側 → 受信側(一方向)
- **接続形態**: 1対1
- **通信環境**: LAN内を想定

## 設計方針

### 優先事項

- 最新の画面状態を重視
- 低遅延を優先
- データ欠損や遅延は許容(放棄)

### 目標性能

- **FPS**: 60FPS程度

## 機能範囲

チャットアプリのVCの画面配信機能を最低限に絞り込んだもの

## 送信側の処理フロー

1. 現在の画面状態を取得
2. 画面データを受信側に送信

## 受信側の処理フロー

1. 送信側から画面データを受信
2. 新しいデータを優先して描画
